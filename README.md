# Controle de estoque

Programa de terminal para cadastrar e consultar produtos e registrar entradas e saídas de estoque.

## Como executar

Com o Python 3 instalado, abra o terminal na pasta do projeto e execute:

```sh
python consulta_de_produtos.py
```

Use o menu para cadastrar produtos e registrar movimentações. O programa cria o arquivo local `estoque.json` ao salvar o estoque e carrega os dados na próxima execução.
